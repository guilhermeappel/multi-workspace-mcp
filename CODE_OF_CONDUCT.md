# Code of conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and constructive. Assume good faith.
- Harassment, discrimination and personal attacks are not welcome in issues, pull requests or discussions.
- Keep feedback about the work, not the person.

The maintainer may edit or remove contributions that break these rules, and may block people who keep doing so.
To report a problem, contact the maintainer through their GitHub profile. Report security issues through the
process in [SECURITY.md](SECURITY.md) instead.
