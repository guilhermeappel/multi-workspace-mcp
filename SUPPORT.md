# Support

This is a small project maintained in spare time, so there is no guaranteed response time.

- **Something does not work.** Check [Troubleshooting](README.md#troubleshooting) and the
  [deployment guide](docs/deployment.md) first. If that does not help, open a bug report and include the version
  or image tag, the host you run it on, and the relevant log lines with every secret removed.
- **You have an idea.** Read the [roadmap](ROADMAP.md), then open a feature request.
- **You found a vulnerability.** Do not open a public issue. Follow [SECURITY.md](SECURITY.md).
- **You want to contribute.** See [CONTRIBUTING.md](CONTRIBUTING.md).
